
## Discord 20mb Compress

## TR
Windows için hazırlanmış discord 20mb sınırına istinaden yapıldı.

Dosya seçerek veya dosyaları pencereye sürükleyip bırakarak toplu işlem kuyruğu oluşturma.
10–20 MB arasında hedef dosya boyutu seçme.
Hızlı, Dengeli ve En İyi kalite ön ayarları.
64, 96, 128 veya 192 kbps AAC ses seçenekleri.
Otomatik, Orijinal, 1080p ve 720p çözünürlük seçenekleri.
NVIDIA NVENC donanım kodlaması; başarısız olursa CPU tabanlı libx264 ile yeniden deneme.
İşlem ilerlemesi, durum ve günlük kayıtlarını arayüzde gösterme.
Kaynak videonun yanına çıktı dosyası kaydetme.

## EN
Developed for Windows with Discord’s 20 MB file size limit in mind.

Create a batch processing queue by selecting files or dragging and dropping them into the window.
Choose a target file size between 10 MB and 20 MB.
Presets for Fast, Balanced, and Best quality.
AAC audio options: 64, 96, 128, or 192 kbps.
Resolution options: Automatic, Original, 1080p, and 720p.
NVIDIA NVENC hardware encoding; falls back to CPU-based libx264 if encoding fails.
Displays processing progress, status, and logs within the interface.
Saves the output file alongside the source video.
